# NyaProg.Modules.Net

Сетевые команды для NyaProg: скачивание файлов и получение значений по HTTP с
раскладкой в переменные. Работает поверх абстракций `IHttpFetcher` / `IFileSystem`
(ядро не зависит от конкретной ОС).

Инструмент: **Net** (`core.net`).

---

## Команда `download` — скачать URL в файл

| Параметр  | Обязателен | По умолчанию | Описание |
|-----------|:----------:|--------------|----------|
| `url`     | да         | —            | URL, шаблон с `{переменными}` |
| `file`    | да         | —            | Путь назначения (абсолютный или относительно рабочего каталога) |
| `headers` | нет        | —            | Заголовки в формате `A: B; C: D` |

Выходные переменные: `file` (итоговый путь), `size` (размер в байтах).

```xml
<download url="https://example.com/fw/{serial}.bin" file="firmware.bin" />
```

## Команда `lookup` — получить значения по URL

| Параметр  | Обязателен | По умолчанию | Описание |
|-----------|:----------:|--------------|----------|
| `url`     | да         | —            | URL, шаблон с `{переменными}` |
| `method`  | нет        | `GET`        | HTTP-метод |
| `headers` | нет        | —            | Заголовки: `A: B; C: D` |
| `extract` | нет        | —            | Правила разбора (см. ниже). Если не задан — тело пишется в `body` |

### Формат `extract`

Список правил через `;`. Каждое правило: `имя=тип:выражение`.

| Тип       | Что делает | Пример |
|-----------|------------|--------|
| `text:`   | всё тело ответа | `token=text:` |
| `regex:`  | первая группа совпадения (или всё совпадение), регистронезависимо, многострочно | `sn=regex:SN([0-9]+)` |
| `json:`   | путь по JSON: `.поле`, `[i]` для массивов | `mac=json:$.network.mac` |

Если `extract` не задан — всё тело пишется в переменную `body`.

### Примеры

```xml
<!-- Значения из JSON REST API -->
<lookup url="https://api.example.com/device/{serial}"
        extract="mac=json:$.network.mac; ip=json:$.network.ip; model=json:$.model" />

<!-- Значение регуляркой из текстового ответа -->
<lookup url="https://example.com/sn.txt" extract="sn=regex:SN([0-9]+)" />

<!-- Сырое значение -->
<lookup url="https://example.com/token" extract="token=text:" />

<!-- С заголовками (ключ API) -->
<lookup url="https://api.example.com/whoami"
        headers="X-Api-Key: SECRET; Accept: application/json"
        extract="sn=json:$.serial" />
```

### Куда попадают значения

Все выходные переменные команды вливаются в **окружение запуска** скрипта.
Дальше их можно использовать:

- как `{переменную}` в параметрах последующих команд (например, `download`/`external`);
- в условиях шага (`cond`).

То есть типовой сценарий «получить серийник → mac/ip → подготовить настройки»
собирается из `lookup` + команды-генератора настроек.

## Локальный пример (FastAPI)

В `examples/fastapi_lookup.py` — простой REST-сервис, отдающий устройство по
серийному номеру. Запуск:

```bash
pip install fastapi uvicorn
uvicorn fastapi_lookup:app --port 8099
```

Проверка через CLI NyaProg (без UI):

```bash
NyaProg.Cli config.xml --exec lookup ^
  "url=http://127.0.0.1:8099/device/SN12345" ^
  "extract=mac=json:$.network.mac; ip=json:$.network.ip; model=json:$.model"
```

Ожидаемый результат:

```
exec 'lookup': Ok
  var mac = AA:BB:CC:DD:EE:FF
  var ip = 10.0.0.5
  var model = GC-0611W4
```

## Замечания

- `regex:` содержит `;`? Разделитель правил — `;`, поэтому в шаблонах лучше
  избегать `;` либо выносить такие правила отдельно.
- Значения `json:` строк возвращаются без кавычек; числа/логические — как есть.
- `lookup`/`download` — это команды уровня утилит: в headless-режиме (`--exec`)
  они не требуют выбранного программатора.
