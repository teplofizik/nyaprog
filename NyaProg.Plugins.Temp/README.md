# NyaProg.Plugins.Temp

Плагин временных файлов: выдаёт путь во временной папке в переменную, чтобы
промежуточные файлы (hex/bin/суммы) не попадали в каталог проекта. В конце их
можно удалить, не трогая файлы проекта.

Корень: `%TEMP%\nyaprog` (`Path.GetTempPath()`).

## Команды

### `tempfile` — путь временного файла в переменную

| Параметр | Обяз. | По умолч. | Описание |
|---|---|---|---|
| `name`   | да    |           | Имя переменной для пути |
| `ext`    | нет   | `tmp`     | Расширение (без точки) |
| `subdir` | нет   |           | Подкаталог под temp |
| `prefix` | нет   | `nyap_`   | Префикс имени |
| `create` | нет   |           | Создать пустой файл (1/true) |
| `keep`   | нет   |           | Не удалять в конце прогона (1/true) |

Выход: переменная `name` = полный путь (уникальное имя: дата-время + GUID).

### `tempdir` — путь временного каталога в переменную

| Параметр | Обяз. | По умолч. | Описание |
|---|---|---|---|
| `name`   | да    |           | Имя переменной для пути |
| `prefix` | нет   | `nyap_`   | Префикс имени |
| `keep`   | нет   |           | Не удалять в конце прогона (1/true) |

Каталог создаётся сразу.

### `delfile` — удалить файл

| Параметр | Обяз. | По умолч. | Описание |
|---|---|---|---|
| `path`   | да    |           | Файл |
| `ok`     | нет   |           | Не ошибка, если файла нет (1/true) |

### `deldir` — удалить каталог (рекурсивно)

| Параметр | Обяз. | По умолч. | Описание |
|---|---|---|---|
| `path`   | да    |           | Каталог |
| `ok`     | нет   |           | Не ошибка, если каталога нет (1/true) |

### `tempclean` — убрать временные файлы сейчас

| Параметр | Обяз. | По умолч. | Описание |
|---|---|---|---|
| `all`    | нет   |           | Удалить всё в корне temp (1/true) |

Без `all` удаляет только зарегистрированные (`$temp`) пути и очищает список.

### `tempinfo` — диагностика

Выводит корень temp, `Path.GetTempPath()`, значения `TMP`/`TEMP`, текущий и
рабочий каталог.

## Важно: имена параметров

Не используйте имена, совпадающие со стандартными переменными окружения
(`dir`, `root`, `soft`, `$dir`) — они подставляются в аргументы команды
автоматически, и **опциональный** параметр молча подхватит их значение.
Поэтому подкаталог назван `subdir` (а не `dir`), а пути удаления — `path`
(а не `file`/`dir`).

## Автоудаление в конце прогона

`tempfile`/`tempdir` регистрируют созданные пути в переменной окружения `$temp`.
По завершении прогона (CLI `--run` и UI) хост вызывает `TempFiles.Cleanup(...)` и
удаляет их — успешно или с ошибкой. Флаг `keep="1"` исключает файл из уборки.

Уборка выполняется движком по завершении, поэтому явный `delfile` не нужен —
он остаётся для удаления в середине прогона.

## Пример

```xml
<steps>
  <tempfile name="hexfile" ext="hex" create="1" comment="временный hex" />
  <bintohex in="{src}" out="{hexfile}" offset="0x08000000" comment="bin -> hex" />
  <filesize file="{hexfile}" var="hexsize" comment="размер hex" />
  <delfile path="{hexfile}" ok="1" comment="убрать временный файл" />
</steps>
```

Проверено: файл создаётся в `%TEMP%\nyaprog`, каталог проекта остаётся чистым
(только исходники), временный файл удаляется в конце.

CLI:

```
NyaProg.Cli config.xml --run "Temp demo" 0
  tempfile: Ok C:\Users\...\Temp\nyaprog\nyap_20261016_122229_125_3fbe81d9.hex
  bintohex: Ok C:\Users\...\Temp\nyaprog\nyap_20261016_122229_125_3fbe81d9.hex
  filesize: Ok
  delfile:  Ok C:\Users\...\Temp\nyaprog\nyap_20261016_122229_125_3fbe81d9.hex
```
